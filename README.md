# Asesor financiero — Unai Ayora

Landing independiente de Nahui Studio.

## Pendiente antes de publicar
1. Sustituir `PENDIENTE_WEB3FORMS_KEY` en `script.js` por la Access Key de Web3Forms.
2. Subir el proyecto a GitHub.
3. Conectar el repositorio con Cloudflare Pages.
4. Conectar el dominio personalizado.
